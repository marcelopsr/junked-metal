# Hecho: catálogo de lo que ya existe

Una ficha corta por pieza: qué es, dónde vive, madurez, cómo se prueba y última nota de crítica. Los pendientes no se repiten acá: viven en [`docs/todos/`](../../todos/README.md).

**Madurez:** estable (probado y sin hallazgos abiertos), usable (anda, con TODOs menores), a medias (falta una parte decidida), congelado (solo recibe cambios compartidos).

Estado tomado del código al 2026-10-21 (`package.json` 0.97.0-dev). La madurez es criterio de quien escribe el catálogo, no una medición.
