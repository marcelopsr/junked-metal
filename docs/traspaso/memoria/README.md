# Memoria del dueño (reglas curadas)

Lo que Marcelo pidió y vale para siempre en este repo, una regla por archivo con **Why** y **How to apply**. Viaja con el repo: la memoria personal de Claude (`~/.claude/projects/…/memory/`) no cruza máquinas ni cuentas. Una regla nueva del dueño se agrega acá y, si es decisión de producto, también como ADR en [../../decisiones/](../../decisiones/README.md).

| Regla | En una línea |
| --- | --- |
| [preguntas.md](preguntas.md) | Toda decisión por AskUserQuestion, antes de trabajar, 4×4 multiselección, recomendada primera; nunca una pregunta suelta en el texto |
| [cerrar-con-propuestas.md](cerrar-con-propuestas.md) | Cada tanda termina proponiendo programas largos para seguir; en loop hasta «basta» |
| [agentes-bajo.md](agentes-bajo.md) | Subagentes solo de esfuerzo bajo, hasta 3 en paralelo con archivos disjuntos; los compartidos los toca el orquestador |
| [probar-una-vez.md](probar-una-vez.md) | Todos los cambios de la tanda y una verificación al final, en proporción al cambio, headless, en segundo plano |
| [servidores.md](servidores.md) | Nadie reinicia `rc-test*`; sin servidores ni puertos propios; un solo navegador liviano |
| [git-sin-destruir.md](git-sin-destruir.md) | Sin `checkout/restore/stash/reset` de archivos: el árbol tiene trabajo de otros |
| [arte.md](arte.md) | El arte lo decide Claude midiendo contra las referencias registradas; toda imagen del dueño es fuente de verdad y se registra |
| [textos.md](textos.md) | Español neutro impersonal, sin voseo; créditos sin tecnología, creador TheDuende; nada de emojis |
| [celular.md](celular.md) | En teléfono nunca 2 jugadores ni split screen |
| [handoff.md](handoff.md) | Siempre dejar handoff completo antes de quedarse sin contexto; el dueño no corre comandos |
| [local.md](local.md) | Todo en esta Mac: sin nube, sin rutinas programadas, sin artifacts publicados, sin Remote Control |
