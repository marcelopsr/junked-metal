# Pixel Art 3D — lote 02: decals

Atlas transparente de ocho overlays: aceite, huellas, hojas, chatarra, chorreaduras de óxido, pintura saltada, barro y franja de peligro. Los PNG fuente conservan alfa y cada tile tiene también WebP lossless de 256×256.

Estado: candidato. El alfa fue comprobado; falta ver cada decal sobre el terreno y las piezas 3D finales para validar escala, bordes y lectura a distancia. No está conectado a las rutas activas.
