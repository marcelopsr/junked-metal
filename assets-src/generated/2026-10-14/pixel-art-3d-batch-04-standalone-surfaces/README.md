# Lote 04 — superficies independientes

Seis PNG autónomos de color base, uno por material; no son un atlas ni hojas de contacto. Se generaron como candidatos de textura repetible, siguiendo el pixel art 3D cálido de la referencia.

| Archivo | Uso previsto |
|---|---|
| `soil-clods.png` | Tierra oscura con terrones, patio y zonas de chatarra. |
| `concrete-gravel.png` | Piso gastado del garaje. |
| `wood-planks.png` | Piso, cajas y tablones. |
| `rusted-red-metal.png` | Chapa pintada y oxidada. |
| `tire-tread-rubber.png` | Caucho con bloques de banda. |
| `grass-dry-leaves.png` | Césped tupido con hojas otoñales. |

Las seis imágenes son RGB de 1254×1254 px. La generación pidió bordes repetibles, pero la continuidad exacta del tile no está validada. Son mapas de color solamente: todavía faltan mapas PBR, reducción a resolución de juego y pruebas de UV/tiling. No están conectadas a materiales activos.
