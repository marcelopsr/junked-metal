Cómo Integrar en src/art_lab.ts

Los modelos exportados son compatibles directamente con B.LoadAssetContainerAsync de Babylon.js 9:

// 1. Cargar vegetación y configurar instancias de matas curvas
const veg = await B.LoadAssetContainerAsync('assets-src/cinematic-3d/gemini-environment/vegetation.glb', scene);
veg.addAllToScene();
const fineTuft = veg.meshes.find(m => m.name === 'GrassTuft_Fine_Mesh');
const broadWeed = veg.meshes.find(m => m.name === 'GrassTuft_Broad_Mesh');

// 2. Cargar cerca y delimitación de pista con cuerda de seguridad
const fence = await B.LoadAssetContainerAsync('assets-src/cinematic-3d/gemini-environment/fence_boundary.glb', scene);
fence.addAllToScene();

// 3. Cargar guirnalda de luces Edison con filamento incandescente brillante
const lights = await B.LoadAssetContainerAsync('assets-src/cinematic-3d/gemini-environment/patio_lights.glb', scene);
lights.addAllToScene();

// 4. Cargar suelo con huellas de neumáticos grabadas
const ground = await B.LoadAssetContainerAsync('assets-src/cinematic-3d/gemini-environment/ground_terrain.glb', scene);
ground.addAllToScene();
