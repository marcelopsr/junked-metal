# Continuidad de arte entre sesiones

El usuario autorizó colaborar entre la sesión visual de Codex y los ciclos de Gemini el 2026-10-10. Antes de tocar arte cinematográfico, leer `docs/VISUAL_SESSION_COORDINATION.md`, sus referencias y el estado Git actual. Mantener el proveedor nativo de cada harness; el usuario puede trasladar los prompts entre sesiones.

No sobrescribir archivos reservados por otra sesión, no integrar recursos experimentales en partidas por iniciativa propia y no incluir WIP ajeno en commits. Trabajar los encargos visuales independientes en sus carpetas asignadas y entregar fuente, exportación, capturas reales y resultado verificable. Registrar lo hecho, lo pendiente y el siguiente paso; no declarar la ilustración igualada ni la integración completada sin evidencia. Las pruebas pesadas comparten candados; usar las herramientas existentes y cerrar el navegador al terminar. Esta muestra es local y no se publica.
